# Assets públicos

Esta pasta reúne somente arquivos autorizados para publicação no site.

## Convenção

```text
assets/
├── images/       # imagens próprias, licenciadas ou autorizadas
└── documents/    # documentos cuja distribuição pública seja permitida
```

## Migração da antiga Wiki

Links no formato `/.attachments/...` pertenciam à estrutura anterior e não devem ser mantidos quando o arquivo original não estiver presente.

Procedimento:

1. localizar o arquivo original no acervo privado;
2. avaliar direitos autorais, privacidade e necessidade editorial;
3. renomear o arquivo de forma descritiva;
4. colocá-lo na subpasta adequada;
5. atualizar a página com link relativo;
6. verificar o funcionamento no GitHub Pages.

Não publicar livros integrais, apresentações de terceiros, imagens privadas ou outros materiais sem autorização.
