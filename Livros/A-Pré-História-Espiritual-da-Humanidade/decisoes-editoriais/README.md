# Decisões editoriais

Esta pasta registra mudanças estruturais relevantes na obra, preservando o motivo e a data da decisão.

## Registrar aqui quando houver

- inclusão, remoção ou fusão de capítulos;
- mudança do arco editorial;
- alteração de título ou público;
- decisão sobre terminologia transversal;
- mudança de tratamento de uma fonte central;
- revisão dos critérios de pronto.

## Convenção

`AAAA-MM-DD-descricao-curta.md`

Decisões rotineiras de redação não precisam de arquivo próprio.
