# Mapas conceituais e de relações

Esta pasta guarda representações estruturadas das relações entre povos, seres, mundos, autores, obras, tradições e conceitos.

Os mapas podem ser mantidos em Markdown, Mermaid ou outro formato textual versionável.

## Regra editorial

Os mapas não fazem parte do manuscrito sequencial do livro. Eles funcionam como **camada transversal de conhecimento**, permitindo navegar entre fontes, personagens, grupos, eventos, cronologias e capítulos.

Mapas selecionados podem ser publicados no site quando tiverem valor explicativo para o leitor, desde que preservem a proveniência das relações e não transformem hipóteses em fatos.
