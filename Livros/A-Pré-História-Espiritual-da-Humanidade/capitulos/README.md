# Capítulos — A Pré-História Espiritual da Humanidade

## Finalidade

Esta pasta contém o **manuscrito do livro**.

Os arquivos numerados são os capítulos que formam a obra e devem ser lidos em sequência.

## Ordem de leitura

1. `00-prologo-por-que-investigar.md`;
2. `01-o-que-chamamos-humanidade.md`;
3. capítulos `02`, `03`, `04` e seguintes, conforme forem criados.

Este `README.md` é apenas uma orientação da pasta e **não faz parte do livro**.

## O que deve ficar aqui

Somente:

- prólogo;
- capítulos numerados;
- epílogo;
- textos finais que integrem diretamente o manuscrito.

Não devem ficar aqui:

- templates;
- fichas de pesquisa;
- transcrições;
- matrizes comparativas;
- pareceres de revisão;
- decisões editoriais;
- arquivos de planejamento.

## Convenção de nomes

`NN-titulo-curto-em-kebab-case.md`

Exemplos:

- `00-prologo-por-que-investigar.md`;
- `01-o-que-chamamos-humanidade.md`;
- `02-como-ler-as-camadas.md`.

## Como criar um capítulo

Use o modelo localizado em:

`../../../../doc/templates/template-capitulo-historia-profunda.md`

Copie sua estrutura, crie o novo arquivo numerado nesta pasta e desenvolva nele o texto da obra.

## Estados editoriais permitidos

- `planejado`;
- `esboço`;
- `pesquisa`;
- `rascunho`;
- `revisão`;
- `pronto`;
- `publicável`.

## Fluxo obrigatório

1. consultar `../../../../commands/producao-capitulos.md`;
2. aplicar `../../../../.agents/skills/escrita-historico-espiritual-comparativa/SKILL.md`;
3. usar o template de `../../../../doc/templates/`;
4. validar com `../criterios-de-pronto-capitulo.md`;
5. atualizar `../sumario-editorial.md` após mudança de estado.

## Capítulos existentes

- `00-prologo-por-que-investigar.md` — `esboço`;
- `01-o-que-chamamos-humanidade.md` — `esboço`.

Arquivos em estado `esboço` já pertencem ao manuscrito, mas ainda não devem ser considerados capítulos concluídos ou prontos para publicação.
