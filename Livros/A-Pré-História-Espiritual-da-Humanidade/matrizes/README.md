# Matrizes comparativas

Esta pasta contém tabelas de trabalho usadas para sustentar capítulos sem sobrecarregar o texto final.

## Tipos previstos

- matriz de afirmações por fonte;
- matriz de convergências e divergências;
- matriz corpo–mente–alma–civilização;
- matriz cronológica;
- matriz de dependência entre autores e obras;
- matriz de evidências e contrapontos.

Cada matriz deve indicar quais capítulos utiliza ou sustenta.
