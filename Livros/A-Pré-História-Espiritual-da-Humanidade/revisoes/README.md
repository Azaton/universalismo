# Revisões editoriais

Esta pasta guarda pareceres de prontidão, revisões epistemológicas e avaliações estruturais dos capítulos.

## Convenção sugerida

`NN-AAAA-MM-DD-tipo-revisao.md`

Exemplos:

- `01-2026-08-15-revisao-epistemologica.md`;
- `01-2026-08-20-parecer-prontidao.md`.

O texto principal do capítulo permanece em `../capitulos/`. Revisões extensas ou históricas ficam aqui para evitar poluir a narrativa.
