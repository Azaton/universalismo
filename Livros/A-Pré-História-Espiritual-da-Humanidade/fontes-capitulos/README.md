# Fontes por capítulo

Esta pasta reúne mapas leves de fontes usados por cada capítulo.

Ela não duplica livros, PDFs ou o acervo do OneDrive. Cada arquivo deve apenas registrar referências, trechos analisados, localização, função no capítulo e pendências de leitura.

## Convenção

`NN-fontes-titulo-curto.md`

Exemplo:

`01-fontes-o-que-chamamos-humanidade.md`

## Conteúdo mínimo

- fonte;
- natureza da fonte;
- localização ou caminho;
- afirmação relevante;
- uso previsto no capítulo;
- status de leitura;
- observações de confiabilidade ou contexto.
